# jQuery Practice Project

A beginner-friendly collection of runnable jQuery examples based on the supplied notes.

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Internet connection is required because the examples load jQuery from the official CDN.
4. Open browser Developer Tools (F12) to see the console message in the Introduction example.

## Topics
- `index.html` — introduction and CDN check
- `selectors.html` — jQuery selectors
- `actions.html` — common actions
- `content-manipulation.html` — `.text()`, `.html()`, `.val()`
- `structure-manipulation.html` — append, prepend, before, after, empty, remove
- `attribute-css.html` — attributes, classes, and CSS
- `events.html` — mouse, keyboard, and form events
- `effects.html` — show/hide, fade, slide, animate
- `traversing.html` — ancestors, descendants, siblings, filtering
- `versions.html` — `noConflict()` with two jQuery versions

Each page has its own JavaScript file in the `js` folder. Shared styling is in `css/style.css`.

Note: jQuery 3.7.1 is used for the regular demos. In the versions demo, jQuery 1.12.4 is included only to demonstrate version conflict handling; use current supported libraries for real projects.
