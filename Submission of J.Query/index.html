jQuery is a JavaScript library that simplifies DOM selection, manipulation, event handling, effects, and AJAX.

Key features

  1. Less code for common JavaScript tasks
  2. Cross-browser helper methods
  3. DOM manipulation and traversal
  4. Simple event handling
  5. Built-in effects and animations
  6. AJAX support
  7. Extensible through plugins

Basic syntax: $(selector).action();
